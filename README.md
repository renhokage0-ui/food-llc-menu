# Food, LLC - Module 3 Solution

Адаптивная страница меню ресторана для задания по Bootstrap 3.

- Репозиторий: https://github.com/renhokage0-ui/food-llc-menu
- GitHub Pages: https://renhokage0-ui.github.io/food-llc-menu/module3-solution/

## Файлы

```text
module3-solution/
  index.html
  css/
    bootstrap.min.css
    styles.css
  js/
    jquery.min.js
    bootstrap.min.js
    menu.js
```

## Реализация

- Bootstrap 3.4.1 и jQuery 3.7.1 подключены локально.
- Панель навигации Food, LLC и кнопка мобильного меню.
- Разделы Chicken, Beef, Sushi ведут к соответствующим секциям.
- На экранах шириной менее 768 px меню раскрывается кнопкой и закрывается после выбора раздела.
- На планшете и компьютере мобильное меню скрыто.
- Заголовок Our Menu расположен по центру.
- Три широкие секции используют сетку Bootstrap `row` / `col-xs-12`; минимальная высота каждой - 1000 px.
- У каждого раздела есть ссылка Back to top; предусмотрены навигация с клавиатуры и уменьшение анимации.

Меню и цены являются примером содержимого учебного сайта.

## Проверка отображения

Проверено в браузере на размерах 1440 x 900 (компьютер), 768 x 1024 (планшет) и 375 x 812 (смартфон).
На всех размерах заголовок расположен по центру, секции занимают доступную ширину, горизонтальная прокрутка отсутствует.
На смартфоне проверены раскрытие меню, переходы к разделам и закрытие меню после быстрого нажатия на ссылку.

## Локальный просмотр

Откройте `module3-solution/index.html` в браузере. Дополнительная установка зависимостей не требуется.

## GitHub Pages

В Settings -> Pages выберите Deploy from a branch, ветку `main`, папку `/ (root)` и нажмите Save.
Главная страница репозитория перенаправляет на `module3-solution/`.
